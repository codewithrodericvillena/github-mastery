# Lesson 01: Git Basics

## Key Commands
- `git init` — Initialize a new local repository.
- `git clone <url>` — Copy a remote repository locally.
- `git status` — Inspect modified and staged files.
- `git add <file>` — Stage changes for the next commit.
- `git commit -m "message"` — Record staged changes in history.

## Practice
1. Check `git status` before every commit.
2. Keep commits focused on a single logical change.
