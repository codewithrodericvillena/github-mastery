# Lesson 08: Stashing and Tags

## Stashing
- `git stash` — Temporarily save uncommitted changes.
- `git stash pop` — Re-apply the most recent stash and remove it from the stash list.
- `git stash list` — View saved stashes.

## Tags & Releases
- `git tag -a v1.0.0 -m "Release v1.0.0"` — Create an annotated tag.
- `git push origin v1.0.0` — Push a tag to GitHub.
