# GitHub Achievements Checklist

- [x] **Quickdraw** — Closed an issue within 5 minutes of opening it.
- [x] **YOLO** — Merged a pull request without code review.
- [x] **Pull Shark** — Merged 2+ pull requests (Bronze: 16, Silver: 128, Gold: 1,024).
- [ ] **Pair Extraordinaire** — Merge a PR with a `Co-authored-by: Name <email>` commit from another GitHub user.
- [ ] **Galaxy Brain** — Have 2+ answers marked as accepted in repository Discussions.
- [ ] **Starstruck** — Receive 16+ stars on an owned repository.
- [ ] **Public Sponsor** — Sponsor an open-source developer or project via GitHub Sponsors.
